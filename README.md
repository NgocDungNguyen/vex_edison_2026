# VEX IQ 2026-27 (Level Up): Team Files

Code, notebooks and competition documents for all teams this season.

## Layout

| Path | What's in it |
|---|---|
| `<team>/DK/` | Driver-control code |
| `<team>/Auto/` | Autonomous code |
| `<team>/Notebook/` | Engineering notebook for that team (drafts, exports, photos, data) |
| `docs/rubrics/` | Official GRSF rubrics 2.0: engineering notebook and team interview, official and student-friendly (A4 PDFs) |
| `docs/templates/` | Official VEX IQ digital notebook template (v5.1), instructions (v4.1), and digital parts images (2026) |
| `docs/research/` | `engineering-notebook-guide.md`: how to write an award-level notebook, templates, checklist, plan to January 2027 |

Teams: `zenith`, `Starlight`, `TieuHoc2`, `TieuHoc4`.

## Notebook workflow

1. Copy `docs/templates/IQ-Digital-Notebook-Template-v5.1.pptx` into your team's `Notebook/` folder and rename it, for example `Zenith_Notebook_v1.pptx`.
2. Students write every entry (no adults, no AI). Mentors ask questions and run the checklist in the research guide.
3. Self-score with the student-friendly rubric in `docs/rubrics/` before each event.
4. Submit the Season, Code and Credit summaries with the notebook.
